# 图表交接示例

适用前提：真实项目中模型章已经由使用者批准。本文件本身不表示批准已经发生。

- 读者问题：构造观测点与拟合直线如何对应，留出检查点位于何处？
- 来源：同目录 `calculate.py` 的五个训练点与一个留出点。所有数据为合成数据，不使用比赛私有文件。
- 表达建议：散点展示训练观测，直线展示拟合关系，空心标记区分留出检查点。训练观测、拟合线与留出点同时用形状和线型区分。
- 信息单元：训练点的线性关系、留出检查点的位置。坐标均为无量纲，不设置双轴或误差区间。
- 图注必须说明：无噪声构造数据与单个留出检查点仅用于计算演示，不代表真实泛化评估。
- 交付：绘图脚本、SVG、PNG、数据来源和视觉检查结果。图件不改变正文参数与数值。
- 若需返修：保留旧版，将新提示词和资产登记为下一版本，明确替代对象；后续章节可继续。
