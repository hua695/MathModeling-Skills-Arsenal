# TikZ 科学制图 Skill — 使用说明

这是一个给 AI 助手用的"绘图技能包"。装好后,你只要**用大白话跟 AI 说要画什么图**,它就能帮你画出论文级别的科研图(数据图、流程图、电路、生物/化学/物理示意图等),并能随时改。

---

## 第一步:安装(一次性,约 10 分钟)

### ① 放好技能包
把 `tikz-scientific-figures.zip` 解压,得到一个 `tikz-scientific-figures` 文件夹,放进 AI 工具的 skills 目录:

- **Claude Code**:放到 `~/.claude/skills/` 文件夹里
- (其他工具放到它的 skills 目录,问对方工具的说明)

放好后重启对话即可。

### ② 装一次绘图引擎(LaTeX)
技能包本身不含绘图引擎,需要在电脑上装一次。**找一段对应你系统的命令,复制到终端运行**:

**Mac**(终端里运行,会让你输一次开机密码):
```bash
brew install --cask basictex
brew install mupdf-tools poppler
eval "$(/usr/libexec/path_helper)"
sudo tlmgr update --self && sudo tlmgr install pgfplots circuitikz standalone chemfig siunitx dvisvgm
```

**Windows**(用管理员 PowerShell;之后请在"Git Bash"里使用):
```powershell
choco install miktex git poppler mupdf
```
> Windows 推荐用 MiKTeX,缺什么绘图组件它会自动下载,基本不用操心。

**Linux(Ubuntu/Debian)**:
```bash
sudo apt-get install texlive-latex-extra texlive-pictures dvisvgm mupdf-tools poppler-utils
```

装完不确定成没成?让 AI 帮你跑一下自检就行(见下方"出问题了")。

---

## 第二步:使用(直接跟 AI 说)

不用懂任何代码,像这样说就行:

- "用 TikZ 画一张论文用的折线图,数据我发给你"
- "画一个 RC 低通滤波器电路图"
- "帮我画小鼠脾脏免疫荧光示意图"
- "画一张神经网络结构图,3 层"

AI 会画好,给你一张 **PDF**(插论文用)和对应的源文件(方便以后改)。

**能画什么:** 折线/柱状/散点/箱线/直方/热图/3D 等数据图 · 电路图 · 流程图/框图/受力图 · 生物(免疫荧光/细胞/通路/基因图)· 化学(分子/反应/能级)· 物理(光路/费曼图)· 数学(交换图/Venn)· 计算机(神经网络/架构/状态机/UML/流程)等。

---

## 改图:三种方式

1. **直接跟 AI 说**(最简单,推荐)
   "把第二条线改成红色虚线""坐标范围改成 0 到 100""这个圆调大点"——AI 改完重新给你图。

2. **自己改数字**
   源文件 `.tex` 最上方有一块"可调参数"(图宽、颜色、范围),会改的可以直接改;数据图直接改 `data.csv` 表格。

3. **拖拽微调**(想精细挪位置时)
   让 AI 把图导成 SVG,用免费网页编辑器打开拖着改:
   - https://boxy-svg.com/app (功能全)
   - https://editor.method.ac (简单)

   ⚠️ 一旦在网页里手动改过,之后就以这个 SVG 为准,别再让 AI 重新生成那张图(会覆盖你的手改)。所以:**大改先让 AI 改,最后才拖拽精修。**

---

## 出问题了?

- **画不出来 / 报错**:直接跟 AI 说"帮我跑一下绘图环境自检",它会告诉你缺什么、怎么补装。
- **图里中文不显示**:跟 AI 说"用中文",它会切换支持中文的引擎。
- **拿不准**:把报错信息发给 AI,它会帮你解决。

就这些,放心用——绝大多数情况你只要动嘴,剩下交给 AI。
