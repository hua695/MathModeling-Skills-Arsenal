# 模型检验方法库

本文件是方法参考，不是新增门禁。硬性验证范围仍以 `core/paper_hard_requirements.md` 和各能力 profile 的 required_evidence 为准；本文件只回答“验证项确定后具体怎么做”。在编写某小问的灵敏度、误差、稳健性段落时按需读取，不自动加载。

所有检验产生的数字必须先进入结果文件或可复现脚本，再写进正文，接受数字一致性与冻结检查；不得在论文中直接写出来历不明的检验数值。

## 一、放置原则

- 默认嵌入每个子问题求解末尾，单问检验篇幅约 0.5 到 1 页，如 5.1.6 灵敏度分析。
- 全部子问题检验内容合计超过 2 页时，在模型评价章汇总关键结论；只有检验内容非常充实才独立设模型检验章。
- 检验对象与该问模型一一对应，不用一段通用套话覆盖所有小问。

## 二、局部灵敏度分析（基础项）

1. 选 3 到 5 个关键参数，即模型核心假设参数或估计量。
2. 固定其余参数，对每个参数分别施加负 20%、负 10%、正 10%、正 20% 扰动。
3. 记录输出变化幅度，列扰动结果表，配龙卷风图或单参数灵敏度曲线。
4. 给出参数敏感度排序与对估计精度的要求。

解读必须落到数字：最敏感参数的输出波动区间、次敏感参数、不敏感参数的波动上限，并说明哪一参数需要重点保证取值准确。

## 三、全局灵敏度分析（美赛优先，国赛冲高可选）

用 Sobol 一阶指数 S1 度量独立贡献，总阶指数 ST 度量含交互的总贡献，ST 减 S1 反映交互强度。计算用 SALib。

```python
from SALib.sample import saltelli
from SALib.analyze import sobol

# problem 给出参数名与取值区间；N 为基础采样数
param_values = saltelli.sample(problem, N)
Y = [model(*row) for row in param_values]
Si = sobol.analyze(problem, np.array(Y))
# Si['S1'] 一阶，Si['ST'] 总阶，Si['S2'] 二阶交互
```

样本量随参数个数增长，采样与模型调用次数须在附录说明；S1、ST 结果以表或条形图给出并解释交互项。

## 四、误差分析（按模型类型选指标）

| 模型类型 | 至少报告 | 建议补充 |
|---|---|---|
| 回归拟合 | MSE、RMSE、MAE、R² | 残差图、Q-Q 图 |
| 预测 | RMSE、MAPE | 预测区间覆盖率、回测 |
| 分类 | 准确率、精确率、召回率、F1、混淆矩阵 | ROC 与 AUC |
| 优化求解 | 目标值、约束满足情况 | 截断误差、收敛判据灵敏度、与替代算法偏差 |
| 机理仿真 | 解析解或实测对照误差 | 相对误差、网格/步长无关性验证 |

残差分析要给结论：残差是否随机分布、是否存在异方差或尾部偏离，以及这对模型假设意味着什么。

## 五、稳健性与稳定性

- Monte Carlo 扰动：对输入或关键参数加随机扰动，分布通常取正态，标准差取真实值或最优值的 5% 到 10%，采样不少于 1000 次，报告输出分布、95% 区间和可靠性随扰动幅度的变化。
- 场景测试：选极端或边界场景验证模型行为合理，例如需求取上下限、约束收紧或放松。
- 随机算法：固定并登记真实 seed，报告多次独立运行的均值与标准差，不能用单次运行曲线证明收敛稳定。

## 六、假设验证

回到模型假设章逐条核验关键假设，每条用 2 到 3 句写明验证方法与结论，假设不成立时说明影响程度。

| 假设 | 验证手段 |
|---|---|
| 线性关系 | 残差图、成分检验 |
| 正态性 | Shapiro-Wilk 或 Q-Q 图 |
| 独立性 | Durbin-Watson 检验 |
| 方差齐性 | Levene 检验、残差散点 |
| 稳态/平稳 | 频谱分析、平稳性检验 |

## 七、对比与回溯

- 多方法对比：用至少两种原理不同的方法解同一问题，报告平均偏差与最大偏差，说明主方法结果可信。
- 回溯验证：用历史数据前段建模、后段预测，与真实值对比，美赛优先采用。
- 弱基准不算对比：对照方法应是该问题公认的强基准或合理基线，不能用明显劣化的稻草人方法衬托主模型。

## 八、按比赛分级

| 检验方法 | 国赛基础 | 国赛冲高 | 美赛基础 |
|---|---|---|---|
| 误差指标 | 必做 | 必做 | 必做 |
| 残差分析 | 推荐 | 必做 | 必做 |
| 局部灵敏度 ±10%/±20% | 必做 | 必做 | 必做 |
| 龙卷风图 | 推荐 | 必做 | 推荐 |
| Sobol 全局灵敏度 | 不要求 | 推荐 | 强烈推荐 |
| Monte Carlo 稳定性 | 不要求 | 必做 | 必做 |
| 假设逐条验证 | 推荐 | 必做 | 必做 |
| 多方法对比 | 推荐 | 必做 | 推荐 |
| 回溯验证 | 不要求 | 推荐 | 必做 |

国赛基础档把必做项嵌入各子问题末尾即可，不要求独立成章；美赛可设独立 Sensitivity Analysis 章，按全局灵敏度、参数稳健性、不确定性量化、场景测试分节。
