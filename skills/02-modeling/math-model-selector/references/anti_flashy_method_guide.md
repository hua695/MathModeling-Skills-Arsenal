# 防炫技方法选择指南

> **核心原则**：方法适配问题，而不是越复杂越好。复杂方法不是默认候选，而是"经论证后获得准入资格"的候选。

---

## 一、通用扎实方法优先级表（P0-P3）

### P0：首选方法（默认先考虑）

| 题型 | P0 方法 | 适用场景 |
|------|---------|----------|
| 优化题 | 贪心算法、规则法、线性规划（LP） | 有明显贪心结构、目标和约束线性、小规模 |
| 预测题 | 均值法、线性回归、移动平均、ARIMA（基础版） | 趋势明显、数据量适中、不需要复杂非线性 |
| 评价题 | 简单加权、熵权法、TOPSIS（基础版） | 指标明确、权重可客观确定 |
| 分类题 | 逻辑回归、决策树（深度≤3） | 特征清晰、可解释性要求高 |
| 机理题 | 最基本的守恒关系、几何关系、微分方程（线性化） | 物理/工程背景明确、可以直接推导 |

### P1：次选方法（P0 明显不足时考虑）

| 题型 | P1 方法 | 适用场景 |
|------|---------|----------|
| 优化题 | 整数规划（MILP）、非线性规划（NLP） | 有整数决策变量、有非线性目标或约束 |
| 预测题 | XGBoost、随机森林、SARIMA | 非线性关系明显、需要特征交互、季节性 |
| 评价题 | 模糊综合评价、灰色关联分析 | 指标模糊、数据不完全、需要处理不确定性 |
| 分类题 | 随机森林、SVM（线性核） | 特征维度较高、需要非线性边界 |
| 机理题 | 非线性 ODE、PDE 数值求解 | 非线性效应显著、空间维度重要 |

### P2：进阶方法（P1 仍不足且有明确证据时考虑）

| 题型 | P2 方法 | 适用场景 |
|------|---------|----------|
| 优化题 | 动态规划、多目标规划（MOO） | 有最优子结构、无后效性、多目标冲突 |
| 预测题 | LightGBM、CatBoost、Prophet | 大规模数据、类别特征多、需要快速训练 |
| 评价题 | 组合评价（Borda+Copeland）、数据包络分析（DEA） | 多评价方法结果冲突、需要效率评估 |
| 分类题 | XGBoost、梯度提升树 | 高精度要求、特征工程充分 |
| 机理题 | 有限元、有限差分、谱方法 | 复杂几何、边界条件复杂 |

### P3：谨慎使用（必须有充分论证，否则不建议）

| 题型 | P3 方法 | 高风险原因 |
|------|---------|-----------|
| 优化题 | 遗传算法、模拟退火、粒子群、强化学习 | 容易"近似"掩盖精确解的存在、参数调优黑箱、可解释性差 |
| 预测题 | LSTM、Transformer、深度学习 | 小样本过拟合、训练不稳定、可解释性差 |
| 评价题 | 神经网络评价、深度学习评价 | 权重黑箱、缺乏理论依据、容易过拟合 |
| 分类题 | 深度学习、集成学习（>5个模型） | 小样本过拟合、计算成本高、可解释性差 |
| 机理题 | 神经网络求解 PDE、物理信息神经网络（PINN） | 训练不稳定、精度难以保证、缺乏理论支撑 |

## 二、复杂度升级树

### 优化类

```text
解析解
  ↓（解析解不存在或太复杂）
线性规划（LP）
  ↓（有整数决策变量）
整数规划（MILP）
  ↓（有非线性目标或约束）
非线性规划（NLP）
  ↓（多目标冲突）
多目标规划（MOO）
  ↓（规模大、NP-hard、精确求解不可行）
启发式算法（GA/SA/PSO）
  ↓（动态决策、序列决策、环境可交互）
强化学习（RL）
```

### 预测类

```text
均值法/朴素预测
  ↓（有明显趋势）
线性回归/移动平均
  ↓（有季节性或自相关）
ARIMA/SARIMA
  ↓（非线性关系明显）
XGBoost/随机森林
  ↓（大规模数据、复杂时序依赖）
LSTM/Transformer
```

### 评价类

```text
简单加权
  ↓（权重需要客观确定）
熵权法/TOPSIS
  ↓（指标模糊或数据不完全）
模糊综合评价/灰色关联
  ↓（多方法结果冲突）
组合评价（Borda+Copeland）
```

### 使用规则

1. 模型只能在前一级明显不足时继续升级
2. 禁止跳跃式升级（如从线性规划直接跳到强化学习）
3. 每次升级需要留一条"升级记录"：上一层的哪个缺陷促使升级

## 三、炫技检测清单（精简版，8 项）

### 高风险信号（命中任意 2 项即需警惕）

| # | 信号 | 典型表现 | 正确做法 |
|---|------|---------|---------|
| 1 | **小规模用复杂方法** | 几十个变量用遗传算法"近似"，本来可以精确求解 | 先试精确求解，确实不可行再用启发式 |
| 2 | **静态优化用强化学习** | 一次性优化问题直接上 PPO/DQN | 静态优化用数学规划，强化学习只用于动态决策 |
| 3 | **小样本用深度学习** | 几百条数据用 LSTM/Transformer | 小样本优先用统计方法或简单 ML，深度学习需要 >1w 样本 |
| 4 | **无时间序列用 LSTM** | 普通表格数据用 LSTM/Transformer | LSTM 只用于有序列依赖的数据，普通表格用 XGBoost/随机森林 |
| 5 | **方法堆叠** | 集成了 5+ 个模型，或者"XX+YY+ZZ"组合 | 集成不超过 3 个模型，组合必须有明确理由 |
| 6 | **SOTA 情结** | 论文中出现"SOTA""最先进""最新模型"等表述 | 竞赛不追 SOTA，追的是问题适配和扎实程度 |
| 7 | **每小问换方法体系** | 三个问题三个完全不同的领域，没有统一建模视角 | 尽量保持统一建模视角，小问之间有递进关系 |
| 8 | **启发式不给数学规划模型** | 只说"用了遗传算法"，不说优化目标和约束是什么 | 启发式必须先给出数学规划模型（目标+约束），再说明为什么精确求解不可行 |

### 自检方法：方法名剥离审查

把摘要和正文中所有方法名遮掉，只看逻辑链：

```
问题是什么 → 建立了什么关系 → 怎么求解 → 结果如何
```

- **逻辑链在遮住术语后仍成立** = 方法为问题服务，扎实
- **一遮术语就散架** = 术语堆砌，炫技

## 四、模型-假设一致性检查

### 正向检查：题目条件 → 是否支持模型假设

逐条检查模型的每个假设是否能从题目条件或常识中推导出来。

| 检查项 | 问题 |
|--------|------|
| 假设来源 | 这个假设是题目明确给的，还是我们自己加的？ |
| 假设合理性 | 如果是自己加的，有没有合理依据（常识、文献、数据）？ |
| 假设代价 | 这个假设简化了什么？代价是什么？对结果影响多大？ |

### 反向检查：模型需要的假设 → 题目是否真的允许

逐条检查模型运行所需的前提条件，题目是否真的提供或允许。

| 算法 | 常见强行假设 | 检查问题 |
|------|-------------|---------|
| 强化学习 | 强行构造奖励函数、假设环境可交互 | 题目真的是动态决策吗？环境真的可交互吗？ |
| 马尔可夫链 | 强行假设无后效性 | 状态转移真的只依赖当前状态吗？ |
| 线性规划 | 直接假设所有关系线性 | 目标和约束真的都是线性的吗？ |
| 神经网络 | 假设样本量足够、假设数据有非线性结构 | 样本量真的够吗（>1w）？数据真的有非线性结构吗？ |
| 时间序列模型 | 假设有时间依赖结构 | 数据真的是时间序列吗？有自相关吗？ |
| 贝叶斯方法 | 强行指定先验分布 | 先验分布有依据吗？还是随便选的？ |

### 常见"为算法造假设"的信号

1. 假设列表很长（>5条），且大部分是为了适配算法而不是简化问题
2. 假设中出现"为了使用 XX 方法，我们假设..."的表述
3. 假设与题目条件明显冲突，但没有说明如何处理冲突
4. 假设的代价没有分析，不知道对结果影响多大

如果模型需要的条件无法由题目或数据支持，应降低优先级或更换方法。

## 五、方法选择决策流程（7 问）

在选择方法前，必须回答以下 7 个问题：

### A. 问题结构（3 问）

1. **核心矛盾是什么？**（用一句话说清楚）
2. **题目真正要求的是预测、解释、优化、评价还是决策？**
3. **数据规模、维度和噪声水平是否支持该方法？**（样本量够不够？有没有标签？量纲是否齐？）

### B. 方法匹配（2 问）

4. **该方法具体解决核心矛盾的哪一部分？**
5. **该方法要求的前提假设是否满足？**（正向：题目→假设；反向：假设→题目）

### C. 升级合理性（2 问）

6. **简单方法具体失败在哪里？**（必须具体，不能说"不够好"）
7. **复杂方法是否直接针对这些失败点？性能提升是否足以抵消复杂度、解释性和计算成本？**

---

## 六、最重要的三句话

1. **复杂方法不是默认候选，而是"经论证后获得准入资格"的候选。**
2. **没有 baseline，不允许直接使用复杂模型；没有证明简单模型失败，不允许升级。**
3. **如果两个模型效果接近，优先选择更简单、更稳定、更可解释的模型。**
