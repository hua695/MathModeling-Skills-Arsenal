# 启发式算法代码注释规范

本规范适用于遗传算法（GA）、模拟退火（SA）、粒子群（PSO）、蒙特卡洛、NSGA-II 等启发式算法的代码。注释必须是纯粹的技术说明，禁止元话语、负向回响、内部讨论和 AI 协作痕迹。

## 一、必须有注释的位置

### 2. 算法参数

每个算法参数必须注释说明含义、取值依据、对结果的影响。

```python
# 初始温度：基于目标函数量级估算，T0=100时接受概率约0.8
T_INIT = 100.0
# 冷却率：0.95（几何冷却，每轮温度降5%），太慢则迭代次数多，太快则易陷入局部最优
ALPHA = 0.95
# 每个温度下的迭代次数：100（与变量数正相关，变量越多需要越多迭代）
L = 100
# 终止温度：0.01（低于此温度时接受差解概率<1%）
T_MIN = 0.01
# 最大迭代次数：5000（防止无限循环，竞赛时间约束）
MAX_ITER = 5000
```

### 3. 适应度函数

适应度函数必须注释说明目标含义、各项权重、约束处理方式。

```python
def fitness(layout):
    """适应度函数：总航行距离（越小越好）
    输入：layout - 测线位置列表
    输出：总航行距离（米），不可行时返回无穷大
    """
    # 计算每条测线长度 + 测线间转移距离
    total = sum(line_length(x) for x in layout)
    total += sum(transfer_distance(layout[i], layout[i+1]) for i in range(len(layout)-1))
    # 约束惩罚：重叠率<15%时加惩罚（不可行解）
    overlap_penalty = sum(max(0, 0.15 - overlap(layout[i], layout[i+1])) * 10000
                          for i in range(len(layout)-1))
    return total + overlap_penalty
```

### 4. 核心算法步骤

每个关键算法步骤必须注释说明做什么、为什么这么做。

```python
# 步骤1：随机生成初始解（均匀分布在可行域内）
current = random_solution(n_var, bounds)
current_fit = fitness(current)

# 步骤2：温度循环（外层），温度从T_INIT按ALPHA冷却到T_MIN
for t in range(max_iter):
    # 步骤3：每个温度下迭代L次（内层），保证热平衡
    for _ in range(L):
        # 步骤4：生成邻域解（高斯扰动，幅度随温度减小，低温时精细搜索）
        neighbor = perturb(current, T, bounds)
        neighbor_fit = fitness(neighbor)
        delta = current_fit - neighbor_fit  # 负值=neighbor更好（最小化视角）
        # 步骤5：Metropolis接受准则：好解直接接受，差解以概率exp(delta/T)接受
        if delta > 0 or random.random() < math.exp(delta / T):
            current = neighbor
            current_fit = neighbor_fit
    # 步骤6：冷却（温度下降）
    T *= ALPHA
```

## 二、注释内容红线

注释中**禁止**出现以下内容：

| 类别 | 禁止内容 | 错误示例 | 正确做法 |
|------|---------|---------|---------|
| 内部讨论 | 经讨论、团队决定、agent建议 | `# 经讨论决定用SA` | `# 模拟退火求解，初始温度100` |
| AI思考 | 首先、其次、让我、经过分析 | `# 首先初始化，然后迭代，最后输出` | `# 步骤1：随机生成初始解` |
| 元话语 | 本文将、以下代码、接下来 | `# 以下代码实现模拟退火` | `# 模拟退火主循环` |
| 负向回响 | 之前用、v2修正、尝试了、失败 | `# 之前用PSO效果不好，改用SA` | `# 模拟退火求解，邻域=高斯扰动` |
| AI协作 | agent、prompt、审查、由H5生成 | `# 由H5 agent生成` | 直接删除 |

## 三、不需要注释的位置

- 显而易见的代码（`import numpy as np`、`for i in range(n):`）
- 简单的变量赋值（`n = 10`、`result = []`）
- 标准库函数调用（`print(...)`、`len(...)`）
- 算法名称已经自解释的简单调用

## 四、注释密度参考

| 代码类型 | 注释密度 |
|---------|---------|
| 算法参数定义 | 每个参数1行注释（含义+取值依据+影响） |
