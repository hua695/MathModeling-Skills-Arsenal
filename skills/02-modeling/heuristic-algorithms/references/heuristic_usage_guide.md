# 启发式算法使用条件与防炫技指南

> **核心原则**：启发式不是默认选择，而是"精确求解不可行后的最后手段"。使用启发式必须有充分理由，不能因为"听起来高级"就用。

---

## 一、启发式算法使用的前置条件

### 必须同时满足的 3 个条件

| # | 条件 | 验证方法 |
|---|------|---------|
| 1 | **精确求解不可行** | 复杂度分析（NP-hard）或实际运行超时（>10 分钟无结果） |
| 2 | **有明确的数学规划模型** | 决策变量、目标函数、约束条件完整定义 |
| 3 | **有 baseline 对比** | 贪心/规则法/局部搜索的结果作为基准 |

### 不满足条件时的正确做法

| 情况 | 正确做法 |
|------|---------|
| 精确求解可行 | 用 pyomo 精确求解，不要用启发式 |
| 没有数学规划模型 | 先建立模型，再考虑求解方法 |
| 没有 baseline | 先做贪心/规则法 baseline，再用启发式提升 |

## 二、各启发式算法的适用场景

### 遗传算法（GA）

| 维度 | 说明 |
|------|------|
| **适用场景** | 离散组合优化、大规模问题、目标函数不可导 |
| **不适用场景** | 小规模问题（<100 变量）、连续凸优化、有精确求解器可用 |
| **必须提供** | 编码方式、适应度函数、选择/交叉/变异算子、参数范围、收敛判据 |
| **常见炫技信号** | 几十个变量用 GA"近似"，本来可以精确求解 |

### 模拟退火（SA）

| 维度 | 说明 |
|------|------|
| **适用场景** | 局部最优多的组合优化、需要跳出局部最优 |
| **不适用场景** | 小规模问题、收敛速度要求高、参数难以调优 |
| **必须提供** | 邻域结构、初始温度、降温策略、终止条件、多次运行统计 |
| **常见炫技信号** | 只说"用了模拟退火"，不给温度参数和降温策略 |

### 粒子群（PSO）

| 维度 | 说明 |
|------|------|
| **适用场景** | 连续变量优化、非凸目标函数、多模态问题 |
| **不适用场景** | 离散优化、约束复杂的问题、需要全局最优证明 |
| **必须提供** | 粒子数、惯性权重、学习因子、速度范围、收敛判据 |
| **常见炫技信号** | 参数敏感却不做参数分析，只说"经过调参效果好" |

### 蒙特卡洛模拟

| 维度 | 说明 |
|------|------|
| **适用场景** | 不确定性分析、风险评估、复杂系统仿真、积分计算 |
| **不适用场景** | 确定性优化、可以解析计算的问题 |
| **必须提供** | 随机变量分布、抽样次数、置信区间、收敛性分析 |
| **常见炫技信号** | 抽样次数太少（<1000）却声称结果可靠，不给置信区间 |

### NSGA-II（多目标遗传算法）

| 维度 | 说明 |
|------|------|
| **适用场景** | 多目标优化、Pareto 前沿求解、目标冲突明显 |
| **不适用场景** | 单目标优化、目标可以加权合成、小规模问题 |
| **必须提供** | 目标函数列表、种群大小、交叉/变异概率、Pareto 前沿可视化 |
| **常见炫技信号** | 两个目标明显可以加权，却用 NSGA-II 求 Pareto 前沿 |

## 三、启发式算法的硬要求（论文必须包含）

### 1. 数学规划模型

必须先给出完整的数学规划模型：

- 决策变量定义（符号、含义、范围）
- 目标函数（最小化/最大化）
- 约束条件（所有约束，包括等式和不等式）
- 问题复杂度分析（为什么精确求解不可行）

### 2. Baseline 对比

必须有简单方法的结果作为对比：

- 贪心算法或规则法的结果
- 局部搜索的结果（如适用）
- 精确求解的结果（如小规模可解）
- 对比表格：方法、目标值、计算时间、最优性差距

### 3. 参数调优

必须说明参数是怎么选的：

- 参数范围（如种群大小 50-200，交叉概率 0.6-0.9）
- 调参方法（网格搜索、随机搜索、经验法）
- 最终参数值及选择理由
- 参数敏感性分析（参数变化对结果的影响）

### 4. 收敛性分析

必须证明算法收敛了：

- 收敛曲线（目标值随迭代次数的变化）
- 终止条件（如连续 50 代无改进）
- 多次运行的统计结果（均值、方差、最优值、最差值）
- 与理论下界的对比（如适用）

### 5. 结果稳定性

必须证明结果稳定：

- 固定随机种子（可复现）
- 多次运行（至少 10 次）的统计结果
- 结果分布（直方图或箱线图）
- 与 baseline 的显著性检验（如适用）

## 四、启发式炫技检测清单

### 高风险信号（命中任意 2 项即需警惕）

| # | 信号 | 问题 | 正确做法 |
|---|------|------|---------|
| 1 | **小规模用启发式** | 几十个变量用 GA/PSO，本来可以精确求解 | 先试精确求解，确实不可行再用启发式 |
| 2 | **没有数学规划模型** | 只说"用了遗传算法"，不说优化目标和约束 | 先给完整的数学规划模型，再说明求解方法 |
| 3 | **没有 baseline 对比** | 直接上启发式，没有简单方法的结果作对比 | 先做贪心/规则法 baseline，再用启发式提升 |
| 4 | **参数黑箱** | 只说"经过调参"，不给参数范围和调参方法 | 给出参数范围、调参方法、最终参数值 |
| 5 | **没有收敛性分析** | 只给最终结果，不给收敛曲线和终止条件 | 给出收敛曲线、终止条件、多次运行统计 |
| 6 | **结果不可复现** | 不固定随机种子，每次运行结果不同 | 固定随机种子，给出多次运行的统计结果 |
| 7 | **静态优化用强化学习** | 一次性优化问题用 PPO/DQN | 静态优化用数学规划或传统启发式，RL 只用于动态决策 |
| 8 | **方法名堆砌** | "GA+SA+PSO 混合算法"，说不清各自作用 | 每个方法必须有明确分工，混合必须有理由 |

## 五、启发式 vs 精确求解的决策流程

```text
有优化问题
  ↓
能建立数学规划模型吗？
  ├─ 不能 → 先建立模型，不要急着选求解器
  └─ 能 → ↓
      问题规模多大？
      ├─ 小规模（<100 变量）→ 用 pyomo 精确求解（LP/MILP/NLP）
      └─ 大规模（>1000 变量）或 NP-hard → ↓
          精确求解超时吗？
          ├─ 不超时 → 还是用精确求解
          └─ 超时 → ↓
              有贪心/规则法 baseline 吗？
              ├─ 没有 → 先做 baseline
              └─ 有 → ↓
                  选择合适的启发式（GA/SA/PSO/蒙特卡洛）
                  必须满足：参数调优 + 收敛性分析 + 结果稳定性 + 与 baseline 对比
```

## 六、论文写作建议

### 好的结构

```
3.2 问题二的求解方法
3.2.1 数学规划模型
  - 决策变量：...
  - 目标函数：...
  - 约束条件：...
3.2.2 精确求解的局限性
  - 问题复杂度分析：...
  - 实际运行结果：超时/内存不足
3.2.3 基于遗传算法的求解方法
  - 编码方式：...
  - 适应度函数：...
  - 选择/交叉/变异算子：...
  - 参数设置及调优：...
3.2.4 结果与分析
  - 收敛曲线：...
  - 与 baseline 对比：...
  - 多次运行统计：...
  - 参数敏感性分析：...
```

### 避免的写法

- "我们使用了遗传算法进行优化，得到了很好的结果"（没有模型、没有参数、没有对比）
- "经过大量调参，最终选择了种群大小 100，交叉概率 0.8"（没有调参过程）
- "算法收敛很快，效果很好"（没有收敛曲线和终止条件）

---

## 七、最重要的三句话

1. **启发式不是默认选择，而是精确求解不可行后的最后手段。**
2. **使用启发式必须先给数学规划模型、先建 baseline、先证明精确求解不可行。**
3. **启发式的结果必须有参数调优、收敛性分析、结果稳定性、与 baseline 对比，否则不可信。**
