# B题建模求解章节模板库

按近五年（2021-2025）国赛B题归纳的建模求解章节模板。拿到题目先逐问判定形态，再按形态取对应模板文件。

## 使用流程

1. 数大问数。2问结构（2022型）只用 problem1、problem2；4问结构全用
2. 逐问判定形态，查下方判定表定位
3. 取对应形态文件，共享模块引用 shared/
4. 按骨架填充，衔接句参考 shared/transition_guide.md

## 近五年形态组合表

| 年份 | 问一 | 问二 | 问三 | 问四 |
|---|---|---|---|---|
| 2021 | 数据拟合 | 并列模块（影响分析） | 优化决策 | 实验设计 |
| 2022 | 机理建模（3子问） | 平行推广 | 无 | 无 |
| 2023 | 机理建模 | 承接扩展 | 优化决策 | 综合应用 |
| 2024 | 统计决策建模 | 并列模块 | 推广型 | 重做型 |
| 2025 | 机理建模 | 承接扩展（算法应用） | 推广型（机理扩展） | 重做型（修正变体） |

## 形态判定表

### 问一类型判定

- 机理建模：物理/几何关系明确，推导建立模型，如2022、2023、2025
- 数据拟合：关系未知，由数据回归/插值建立，如2021
- 统计决策：按风险/信度做方案设计，如2024

### 问二与问一的关系判定

- 承接扩展：加参数/加条件，复用原模型，如2023、2025
- 平行推广：换场景，模型结构不变，如2022
- 并列模块：独立建模，仅沿用问一数据或结论，如2024、2021

### 问三类型判定

- 优化决策：目标函数+约束+最优方案，如2021、2023
- 推广型：从特例推广到一般情形，或深入机理扩展，如2024、2025

### 问四类型判定

- 重做型：条件变化后全流程重跑，或模型修正+重算，如2024、2025
- 综合应用：真实数据/复杂场景应用，或实验设计，如2023、2021

## 文件索引

- problem2/_README.md：问二选择指针，形态A-C
- problem3/_README.md：问三选择指针，形态A-B
- problem4/_README.md：问四选择指针，形态A-B
- shared/：跨形态通用模块

## 通用硬约束（所有形态必须遵守）

1. 引言段在节标题下，直接在5.x标题下，不是在5.x.1之前
2. 先判定形态再写，不要混用
3. 引用式写法：复用前问模型时写"引用式（X），不再重复推导"
4. 只推导新增部分，不从头推导
5. 结果格式：按题目要求的表格格式输出，保存为resultX.xlsx
6. 反机械约束：每个公式前有文字引导、后有解释，关键推导配图，连续公式不超过3个
7. 篇幅控制：问一约占全文25%-30%，问二约20%，问三约25%，问四约20%
8. 子问结构支持：某问含(1)(2)时，5.x.1问题(1)内嵌"模型建立→求解"，5.x.2问题(2)同理
