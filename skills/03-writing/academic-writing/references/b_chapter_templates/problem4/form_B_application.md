# 问题四形态B：综合应用（2023/2021型）骨架版

> 本文件为骨架版，包含骨架结构和必选项清单。写作要点和特色空间待后续细化。

## 适用场景

真实数据/复杂场景应用，或实验设计。需要数据预处理、应用模型求解、指标计算、效果评估。

典型例子：2023问四（基于单波束测深数据设计多波束测深测线）、2021问四（设计补充实验）。

---

## 骨架结构（固定顺序）

```
5.4 问题四：[问题核心概括]

【引言段】（1段，直接在5.4标题下）
  - 第1句：问题要求
  - 第2句："将前问模型应用于真实数据场景，满足...约束"或"在前问模型基础上，设计补充实验以提升模型可靠性"

5.4.1 数据预处理与初貌分析（带附件数据的题目必须）
  - 建立坐标系（必须）
  - 数据预处理（必须，清洗、特征提取等）
  - 数据可视化（必须，三维图、等深线图等）
  - 分析数据特征（必须）

5.4.2 应用模型求解
  ■ 复用说明（必须，说明哪些部分复用前问模型）
  ■ 区域划分/问题分解（可选，复杂场景需要）
  ■ 约束适配（必须，条带覆盖、重叠率上限等）
  ■ 新增子模型（可选，比如最小二乘拟合坡面方程）
  ■ 求解方法（必须）
  ■ 算法选择理由（必须，如果用了新算法）

5.4.3 指标计算与结果呈现
  - 题目要求指标逐项计算（必须，总长、漏测占比、超限重叠长度等）
  - 结果表格（必须）
  - 结果图（必须，最终方案可视化图）
  - 分区/分情况处理（可选，复杂场景需要，①②③④每个区域的处理方式）

5.4.4 结果分析与效果评估
  - ▣ 结果分析（必须，分点，包含与前问结果的对比）
  - 指标含义解读（必须）
  - 模型局限与改进方向（可选）
  - 效果评估（可选，全覆盖/漏测/冗余分析）
```

## 必选项清单

| 部分 | 必选项 |
|------|--------|
| **引言段** | ①问题要求 ②应用场景说明 |
| **数据预处理**（带数据必须） | ①数据清洗 ②特征提取 ③数据可视化 ④数据分析 |
| **复用说明** | ①哪些部分复用前问模型 ②引用式（X） |
| **约束适配** | ①新场景的约束条件 ②约束来源说明 |
| **求解方法** | ①用什么方法求解 ②关键参数设置 |
| **算法选择理由**（新算法必须） | ①为什么选这个算法 ②对比其他算法 |
| **指标计算** | ①题目要求的所有指标 ②逐项计算 |
| **结果呈现** | ①结果表格 ②结果图 ③单位明确 |
| **结果分析** | ①分点分析 ②与前问结果对比 ③解读数值含义 |
| **效果评估** | ①方案优劣评价 ②模型局限说明 |

## 实验设计变体（2021型）

如果是实验设计题，把"数据预处理+应用求解"换成"实验设计"：

```
5.4.1 设计准则
  ■ 现有数据的覆盖缺口（必须，哪些组合/温度区间未覆盖）
  ■ 信息增益最大化的原则（必须）

5.4.2 实验方案
  ■ N次实验逐次给出（必须，参数选择+理由）
  ■ 预期收益分析（必须，对模型改进的具体贡献）
```

## 与形态A的区别

| 部分 | 形态A（重做型） | 形态B（综合应用） |
|------|----------------|------------------|
| 核心任务 | 条件变化后全流程重跑 | 真实数据/复杂场景应用 |
| 重点 | 参数更新+结果对比 | 数据预处理+应用求解+指标计算 |
| 数据 | 通常不需要新数据 | 通常带附件数据，需要预处理 |
| 结果 | 新旧结果对比 | 指标计算+效果评估 |

其余通用硬约束、共享模块引用与形态A相同。
