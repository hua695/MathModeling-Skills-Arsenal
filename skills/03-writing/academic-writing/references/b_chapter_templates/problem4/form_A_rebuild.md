# 问题四形态A：重做型（2024/2025型）骨架版

> 本文件为骨架版，包含骨架结构和必选项清单。写作要点和特色空间待后续细化。

## 适用场景

条件变化后全流程重跑，或模型修正+重算。需要参数更新说明、全流程重跑、结果对比。

典型例子：2024问四（条件变化后重做问题2、3）、2025问四（模型修正+重算）。

---

## 骨架结构（固定顺序）

```
5.4 问题四：[问题核心概括]

【引言段】（1段，直接在5.4标题下，重点说清"参数更新方式"）
  - 第1句：问题要求
  - 第2句："条件由X变为Y，本问重做问题X"或"本问识别误差来源并修正模型，重新计算"

5.4.1 参数更新说明
  ■ 哪些参数口径变化（必须，如次品率改由抽样检测得到）
  ■ 新参数来源与取值（必须）
  ■ 模型修正（可选，2025型：误差来源识别+模型修正）

5.4.2 全流程重跑
  ■ 复用原模型，只更新输入（必须，引用式（X），不再重复推导）
  ■ 计算流程（必须）
  ■ 求解方法（必须）

5.4.3 结果对比
  ■ 新旧结果对比表（必须）
  ■ 差异归因（必须，为什么变了，变在哪一问）
  ■ 结论修正（必须）
  ■ ▣ 结果分析（必须，分点）
```

---

## 必选项清单

| 部分 | 必选项 |
|------|--------|
| **引言段** | ①问题要求 ②参数更新方式或模型修正方式 |
| **参数更新说明** | ①哪些参数口径变化 ②新参数来源与取值 |
| **模型修正**（2025型） | ①误差来源识别 ②模型修正方式 |
| **全流程重跑** | ①复用原模型，引用式（X） ②只更新输入，不重复推导 ③计算流程 |
| **结果对比** | ①新旧结果对比表 ②差异归因 ③结论修正 |
| **结果分析** | ①分点分析 ②解读变化原因 ③模型可靠性 |

## 修正变体（2025型）

把"参数更新"换成"误差来源识别+模型修正"，其余结构不变：

```
5.4.1 误差来源识别与模型修正
  ■ 误差来源识别（必须）
  ■ 模型修正方式（必须）
  ■ 修正后的模型（必须，boxed）
```

## 与形态B的区别

| 部分 | 形态A（重做型） | 形态B（综合应用） |
|------|----------------|------------------|
| 核心任务 | 条件变化后全流程重跑 | 真实数据/复杂场景应用 |
| 重点 | 参数更新+结果对比 | 数据预处理+应用求解+指标计算 |
| 复用 | 复用原模型，只更新输入 | 复用前问模型，适配新场景约束 |
| 结果 | 新旧结果对比 | 指标计算+效果评估 |

其余通用硬约束、共享模块引用与形态B相同。
