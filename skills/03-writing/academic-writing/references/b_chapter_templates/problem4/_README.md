# 问题四选择指针

按问题类型二选一：

| 形态 | 判定标准 | 年份例子 | 模板文件 |
|------|---------|---------|---------|
| A. 重做型 | 条件变化后全流程重跑，或模型修正+重算 | 2024、2025 | form_A_rebuild.md |
| B. 综合应用 | 真实数据/复杂场景应用，或实验设计 | 2023、2021 | form_B_application.md |

## 判定要点

- 重做型：题目要求"在...条件下重新求解""考虑...因素后修正模型并重算"等，需要全流程重跑
- 综合应用：题目要求"应用于真实数据""设计...方案""设计补充实验"等，需要在复杂场景下应用

形态判定与整题组合见根README。

## 通用硬约束

1. 引言段在节标题下，直接在5.4标题下
2. 先判定形态再写，不要混用
3. 引用式写法：复用前问模型时写"引用式（X），不再重复推导"
4. 大量复用前面问题的模型，只推导新增/变化的部分
5. 结果格式：按题目要求的表格格式输出，保存为resultX.xlsx
6. 反机械约束：每个公式前有文字引导、后有解释，关键推导配图，连续公式不超过3个
7. 篇幅控制：问题四约占全文20%
8. 子问结构支持：问题四含(1)(2)时，5.4.1问题(1)内嵌"模型建立→求解"，5.4.2问题(2)同理
