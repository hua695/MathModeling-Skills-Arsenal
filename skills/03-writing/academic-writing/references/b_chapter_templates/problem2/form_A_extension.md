# 问题二形态A：承接扩展（2023/2025型）骨架版

> 本文件为骨架版，包含骨架结构和必选项清单。写作要点和特色空间待后续细化，可参考问题一完整模板的对应部分。

## 适用场景

在问题一模型基础上新增参数/自由度，复用问题一的核心模型，只推导新增部分。

典型例子：2023问二（加β夹角，复用问一覆盖宽度模型）、2025问二（算法应用）。

---

## 骨架结构（固定顺序）

```
5.2 问题二：[问题核心概括]

【引言段】（1段，直接在5.2标题下，必须说清"在问一基础上新增了哪个自由度"）

5.2.1 [扩展模型名称]的建立
  ■ 新增/调整假设（必须）
  ■ 复用说明（必须，引用式（X），不再重复推导）
  ■ 新增部分推导（必须，只推新增，分步骤+配图）
  ■ 扩展后综合模型（必须，boxed）
  ■ 模型分析与讨论（必须，重点为新增参数影响）

5.2.2 [求解对象]的求解
  - 求解方法说明（必须）
  - 结果呈现（必须，按题目表格式，resultX.xlsx）
  - ▣ 结果分析（必须，有可比对象就与问一对比；否则对比同指标在不同参数下的变化）
  - 可靠性/误差分析（可插拔，算法类必开）
```

## 必选项清单

| 部分 | 必选项 |
|------|--------|
| **引言段** | ①问题要求 ②与问题一的关系（说清新增了什么自由度） |
| **新增/调整假设** | ①本问新增或调整了哪些假设 ②假设调整的影响 |
| **复用说明** | ①引用问题一的哪个公式/模型 ②明确"不再重复推导" ③复用部分与新增部分的清单 |
| **新增部分推导** | ①分步骤标记 ②每步配图 ③每个公式前有文字引导、后有解释 ④只推新增，不从头推 |
| **综合模型** | ①最终公式用boxed ②变量含义说明 |
| **模型分析与讨论** | ①新增参数的影响 ②极限情况讨论 |
| **求解方法** | ①用什么工具求解 ②关键参数设置 |
| **结果呈现** | ①按题目表格式输出 ②保存为resultX.xlsx ③单位明确 |
| **结果分析** | ①分点分析 ②与问题一对比或参数变化对比 ③解读数值含义 |

## 写作要点（参考问题一完整模板）

- 引言段：参考问题一的引言段写作要点，重点说清与问题一的关系
- 新增部分推导：参考问题一的模型推导写作要点，只推新增部分
- 结果分析：参考问题一的结果分析写作要点，重点做对比
- 衔接句：参考shared/transition_guide.md
- 结果格式：参考shared/result_convention.md
