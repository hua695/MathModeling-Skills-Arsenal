# 问题二形态B：平行推广（2022型）骨架版

> 本文件为骨架版，包含骨架结构和必选项清单。写作要点和特色空间待后续细化。

## 适用场景

把问题一的模型推广到新场景/新构型，核心思路不变，只需做场景适配。

典型例子：2022问二（圆形编队推广到锥形编队）。

---

## 骨架结构（固定顺序）

```
5.2 问题二：[问题核心概括]

【引言段】（1段，说清"问题一模型可推广到...，只需调整..."）

5.2.1 [新场景]的适配
  ■ 场景描述与假设调整（必须）
  ■ 模型适配推导（必须，复用结构，替换场景参数，引用式（X））
  ■ 适配后模型（必须，boxed）

5.2.2 求解与对比
  - 求解方法（必须）
  - 结果呈现（必须，与问一同指标对比表）
  - ▣ 结果分析（必须，推广是否成立、偏差来源）
  - 可靠性/误差分析（可插拔）
```

---

## 必选项清单

| 部分 | 必选项 |
|------|--------|
| **引言段** | ①问题要求 ②推广到什么新场景 ③只需调整哪些设定 |
| **场景描述与假设调整** | ①新场景的特点 ②假设调整的内容 |
| **模型适配推导** | ①复用问题一的哪些结构 ②替换哪些场景参数 ③引用式（X） |
| **适配后模型** | ①最终公式用boxed ②变量含义说明 |
| **求解方法** | ①用什么工具求解 ②关键参数设置 |
| **结果呈现** | ①与问一同指标对比表 ②单位明确 |
| **结果分析** | ①推广是否成立 ②偏差来源分析 ③与问一结果对比 |

---

## 与形态A的区别

| 部分 | 形态A（承接扩展） | 形态B（平行推广） |
|------|------------------|------------------|
| 引言段 | 说清"新增了什么自由度" | 说清"推广到什么新场景，只需调整什么" |
| 推导部分 | "新增部分推导" | "场景适配推导" |
| 结果对比 | 与问题一对比 | 不同场景横向对比 |

其余必选项、写作要点、特色空间与形态A相同。
