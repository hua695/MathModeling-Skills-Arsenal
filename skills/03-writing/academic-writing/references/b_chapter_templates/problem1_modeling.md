# B题问题一（5.1）建模求解章节完整模板

## 第1层：题型判定（必须先做）

写问题一之前，先判定本问属于哪种类型，三种类型三选一：

| 类型 | 判定标准 | 年份例子 |
|------|---------|---------|
| 机理建模 | 物理/几何关系明确，推导建立模型 | 2022、2023、2025 |
| 数据拟合 | 关系未知，由数据回归/插值建立 | 2021 |
| 统计决策 | 按风险/信度做方案设计 | 2024 |

判定后按对应类型的要点调整推导部分，骨架结构通用。

---

## 第2层：骨架结构（固定顺序，不可调换）

```
5.1 问题一：[用一句话概括问题核心]

【引言段】（3句话，直接在5.1标题下）

5.1.1 [具体模型名称]的建立
  ■ 原理与背景（可选，按题目需要，配原理图）
  ■ 模型设定与符号定义（必须，按题目需要配图）
  ■ 模型推导（必须，分步骤，每步配图）
  ■ 综合模型（必须，最终公式用boxed）
  ■ 模型分析与讨论（必须，解释公式含义、极限情况、参数影响）
  ■ 候选建模方法比较（必须，路线比较）
  代数来源展开/推导链补充（可选，方便复核）

5.1.2 [具体求解对象]的求解
  - 求解方法说明（必须）
  - 结果呈现（必须，按题目需要选择形式）
  - ▣ 结果分析（必须，分点，按情况定数量）
  - 结果图（必须，配结果可视化图）

5.1.3 算例验证（必须，把模型跑通）
  - 代入题目给定的参数/数据
  - 运行模型，输出结果
  - 验证结果合理性
```

## 第3层：必选项清单（每个部分必须包含）

| 部分 | 必选项 | 遗漏后果 |
|------|--------|---------|
| **引言段** | ①问题要求 ②建模思路（可以用"首先...然后..."） ③引出下文 | 开头不清，扣分 |
| **原理与背景** | ①问题的物理/工程背景 ②原理示意图（可选但建议） | 背景不清，扣分 |
| **模型设定与符号定义** | ①模型的基本设定（坐标系/决策变量/状态定义等） ②关键符号定义 | 设定不清，扣分 |
| **模型推导** | ①分步骤标记（1)2)3)） ②每步配图 ③每个公式前有文字引导、后有解释 ④连续公式不超过3个 | 推导不清，扣分 |
| **综合模型** | ①最终公式用boxed ②变量含义说明 | 模型不完整 |
| **模型分析与讨论** | ①公式含义解释 ②极限情况讨论 ③参数变化影响 | 分析缺失 |
| **候选建模方法比较** | ①可选方法说明 ②各方法优缺点 ③选择本文方法的理由 | 方法选择无依据 |
| **求解方法** | ①用什么工具求解 ②关键参数设置 | 可复现性差 |
| **结果呈现** | ①数值/表格/图/方案等 ②单位明确 ③数据精确 | 结果缺失 |
| **结果分析** | ①分点分析 ②每个点有明确主题 ③解读数值含义，不只是罗列 | 分析缺失 |
| **算例验证** | ①代入题目参数 ②输出结果 ③验证合理性 | 模型只推导不落地，常见扣分点 |

## 第4层：写作要点（质量要求，但不规定固定句式）

### 引言段写作要点

- 只能有3句话
- 第1句：概括问题要求（不讲具体数值、公式）
- 第2句：概括建模思路（可以用"首先...然后..."自然叙述，不讲具体数值、公式）
- 第3句：引出下文（如"具体操作如下。"，也可以用其他自然表述）
- 不要写"具有重要意义""本文深入研究了"等空话

### 原理与背景写作要点

- 用通俗的语言说明问题的物理/工程背景
- 配1张原理示意图，图题在下方
- 1-2段，每段3-5句话
- 不出现公式
- 不是所有题都需要，按题目需要决定

### 模型设定与符号定义写作要点

- 说明模型的基本设定（坐标系/决策变量/状态定义/参数定义等）
- 定义关键符号，后续推导直接使用
- 按题目需要配图（坐标系图/示意图/流程图等），不是必须配图
- 1段，3-5句话
- 符号定义要完整，不要在推导中突然出现未定义的符号

### 模型推导写作要点

- 用1)2)3)标记推导步骤，每步有明确的小标题
- 每一步配1张示意图，图和文字紧密结合，不是推导完了才放图
- 每一步2-3段文字+1-3个公式
- 每个公式前有文字引导（"由...可得""联立...得""代入...得"）
- 每个公式后有文字解释（变量含义、成立条件、几何意义）
- 连续公式不超过3个，超过必须插入文字解释
- 推导要循序渐进，不要跳步
- 关键中间步骤要保留，不要直接给最终结果

### 综合模型写作要点

- 把前面推导的公式综合起来，给出最终的数学模型
- 最终公式用\boxed{}标记
- 1段文字说明，列出所有公式
- 说明每个变量的含义
- 放在推导的最后，作为本小节的结论

### 模型分析与讨论写作要点

- 解释最终公式的含义，每个项代表什么物理/工程/经济意义
- 讨论公式的极限情况（比如某个参数为0时，公式退化为...）
- 讨论参数变化时结果的变化趋势
- 1-2段，不要太长
- 不要只是重复公式，要有解读

### 候选建模方法比较写作要点

- 说明除了本文方法外，还有哪些可选方法
- 比较各方法的优缺点（精度、复杂度、适用范围、可解释性等）
- 说明为什么选择本文方法（至少2-3条理由）
- 1段，3-5句话
- 不要只说"本文方法更好"，要有具体对比

### 求解方法写作要点

- 说明用什么工具/方法求解（MATLAB/Python/求解器等）
- 说明关键参数设置（初值、范围、终止条件等）
- 1段，2-3句话
- 要让读者能复现结果

### 结果呈现写作要点

- 可能的形式：数值、表格、图、方案、列表等
- 按题目需要选择最合适的呈现方式，不是必须用表格
- 数据精确，单位明确
- 如果是表格，表格标题在上方；如果是图，图题在下方
- 数值保留位数全文一致

### 结果分析写作要点

- 用①②③...分点分析，每个点有明确主题（不是"分析1""分析2"）
- 不只是罗列数值，要解读数值背后的含义
- 指出对后续问题的影响
- 每个点1段，2-4句话
- 按情况定数量，一般3-5个点
- 可以结合图来分析，指着图说

### 算例验证写作要点

- 代入题目给定的参数/数据，把模型跑通
- 输出结果，验证结果合理性
- 说明模型只推导不落地是常见扣分点
- 1-2段
- 如果题目给了具体算例，必须算；如果没给，可以自己设计简单算例

## 第5层：特色空间（可以自由发挥的部分）

以下部分没有固定写法，鼓励根据题目特点和个人理解创新：

1. **推导方式**：用什么方法推导（几何法、向量法、代数法、物理法等），完全自由
2. **配图形式**：示意图怎么画、画什么，完全自由
3. **分析角度**：结果分析从什么角度切入，完全自由
4. **模型讨论深度**：讨论到什么程度、讨论哪些方面，完全自由
5. **可视化形式**：结果图用什么类型（折线图、柱状图、热力图、散点图等），完全自由
6. **算例设计**：如果题目没给算例，自己设计什么算例，完全自由
7. **候选方法选择**：比较哪些方法，从什么角度比较，完全自由

**核心原则**：结构和必选项是固定的，但"怎么写"完全自由。

---

## 反机械硬约束（必须遵守）

1. 每个公式前必须有文字引导，不能直接扔公式
2. 每个公式后必须有文字解释，解释含义、变量、成立条件
3. 关键推导步骤必须配图，每步1张图，图文结合
4. 连续公式不超过3个，超过必须插入文字解释
5. 2级标题必须包含具体内容，不能只用"模型的建立""模型的求解"
6. 结果分析必须解读，不能只罗列数值
7. 原理与背景、模型分析与讨论必须有，不能跳过
8. 段落长度要有变化，不能每段都是3句话，长短句结合
9. 算例验证必须有，模型只推导不落地是常见扣分点
10. 不要写"首先...其次...然后...最后..."这种四个的机械列表连接词
