# 问题三形态A：优化决策（2021/2023型）骨架版

> 本文件为骨架版，包含骨架结构和必选项清单。写作要点和特色空间待后续细化。

## 适用场景

在前面模型基础上建立优化模型，求最优方案。需要决策变量、目标函数、约束条件、求解算法、最优性验证。

典型例子：2021问三、2023问三（最短测线设计）。

---

## 骨架结构（固定顺序）

```
5.3 问题三：[优化问题核心概括]

【引言段】（1段，直接在5.3标题下）
  - 第1句：问题要求
  - 第2句：建模思路（"我们从XX和XX两个方面考虑，通过...得到...；对于...，建立单目标优化模型求解"）

5.3.1 优化模型的建立
  ■ 问题转化（必须，把实际问题转化为优化问题）
  ■ 前置证明/分析（可选，比如证明某个方向最佳、某个性质成立）
  ■ 决策变量定义（必须）
  ■ 目标函数（必须，boxed，说明优化目标）
  ■ 约束条件（必须，逐条列出，说明来源，每条可能有子编号1)2)）
  ■ 复用前问模型（必须，"在问题X中，我们已经给出...的一般定义，在此结合...将...更新为下式"）
  ■ 综合模型（必须，boxed，大括号形式，包含目标函数+所有约束）

5.3.2 [求解算法名称]求解最优方案
  ■ 算法选择理由（必须，说明为什么选这个算法，对比其他算法）
  ■ 算法流程（必须，配流程图）
  ■ 关键步骤说明（Step 1/2/3...）
  ■ 参数设置（必须，初值、范围、终止条件）
  ■ 关键处理（必须，约束处理、局部最优处理、奇异情况处理）

5.3.3 最优方案求解与分析
  - 代入参数求解（必须）
  - 结果呈现（必须，最优方案、目标值）
  - 结果表格（必须）
  - 结果图（必须，最优方案可视化图）
  - ▣ 结果分析（必须，分点）

5.3.4 仿真检验/最优性验证（必须，别省）
  - 用另一种算法/方法对比验证（必须）
  - 结果对比表格（必须）
  - 结果分析（"误差很小，证明了模型的可靠性以及求解结果的精确性"）

5.3.5 灵敏度分析（可选，按题目需要）
  - 关键参数的灵敏度分析
  - 结果图
  - 结果分析
```

## 必选项清单

| 部分 | 必选项 |
|------|--------|
| **引言段** | ①问题要求 ②建模思路（从哪些方面考虑） |
| **问题转化** | ①把实际问题转化为优化问题 ②优化目标说明 |
| **决策变量** | ①决策变量定义 ②变量含义说明 |
| **目标函数** | ①目标函数公式（boxed） ②优化目标说明 |
| **约束条件** | ①逐条列出约束 ②每条约束的来源说明 |
| **综合模型** | ①大括号形式包含目标+所有约束 ②boxed |
| **算法选择理由** | ①为什么选这个算法 ②对比其他算法 |
| **算法流程** | ①流程图 ②Step说明 |
| **参数设置** | ①初值 ②范围 ③终止条件 |
| **最优方案** | ①最优方案呈现 ②目标值 ③结果表格 |
| **结果分析** | ①分点分析 ②解读数值含义 |
| **最优性验证** | ①另一种方法对比 ②误差分析 ③可靠性结论 |

## 优化题特殊要求（别省）

1. **算法选择理由**：必须说明为什么选这个算法，对比其他算法的优缺点
2. **最优性/收敛性验证**：必须用另一种算法或方法对比验证，不能只给一个结果
3. **约束处理说明**：必须说明怎么处理约束（罚函数、投影、修复等）
4. **局部最优处理**：必须说明怎么避免局部最优（多起点、扰动、重启等）
5. **参数敏感性**：关键参数的变化对最优解的影响
