# 问题三形态B：推广型（2024/2025型）骨架版

> 本文件为骨架版，包含骨架结构和必选项清单。写作要点和特色空间待后续细化。

## 适用场景

从特例推广到一般情形，或深入机理扩展。需要参数化表述、一般化模型、求解流程。

典型例子：2024问三（推广到m道工序n个零配件的一般情形）、2025问三（机理扩展，推导必要条件并新建模）。

---

## 骨架结构（固定顺序）

```
5.3 问题三：[推广问题核心概括]

【引言段】（1段，直接在5.3标题下）
  - 第1句：问题要求
  - 第2句："将问题X的模型推广到...一般情形"或"本问深入...机理，推导...必要条件并建立扩展模型"

5.3.1 一般化模型的建立
  ■ 推广说明（必须，说清从特殊到一般的推广）
  ■ 参数化表述（必须，m、n等一般参数）
  ■ 说明问题X是特例（必须，代入特例可还原）
  ■ 一般化目标与约束（必须，boxed）
  ■ 机理扩展（可选，2025型：必要条件推导，分步骤+配图，命题/条件形式收尾）

5.3.2 求解流程设计
  ■ 求解流程（必须，配流程图）
  ■ 算法适配与规模处理（必须，n增大时的复杂度）
  ■ 关键步骤说明
  ■ 参数设置

5.3.3 算例验证与结果分析
  - 特例数据下的求解（必须）
  - 结果呈现（必须，方案表）
  - 与问题X结果对照（必须）
  - ▣ 结果分析（必须，分点）
  - 结果图
```

---

## 必选项清单

| 部分 | 必选项 |
|------|--------|
| **引言段** | ①问题要求 ②推广到什么一般情形 |
| **推广说明** | ①从特殊到一般的推广 ②哪些参数一般化 |
| **参数化表述** | ①m、n等一般参数定义 ②参数含义 |
| **特例可还原** | ①说明问题X是特例 ②代入特例可还原 |
| **一般化模型** | ①一般化目标与约束 ②boxed |
| **求解流程** | ①流程图 ②关键步骤说明 |
| **规模处理** | ①n增大时的复杂度分析 ②适配方法 |
| **算例验证** | ①特例数据下的求解 ②与问题X结果对照 |
| **结果分析** | ①分点分析 ②推广是否成立 ③偏差来源 |

## 与形态A的区别

| 部分 | 形态A（优化决策） | 形态B（推广型） |
|------|------------------|----------------|
| 核心任务 | 求最优方案 | 从特例推广到一般 |
| 模型建立 | 决策变量→目标→约束 | 参数化表述→一般化模型 |
| 求解 | 算法设计+最优性验证 | 求解流程+规模处理 |
| 结果 | 最优方案+对比验证 | 算例验证+与特例对照 |

其余通用硬约束、共享模块引用与形态A相同。
