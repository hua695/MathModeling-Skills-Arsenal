# 问题三选择指针

按问题类型二选一：

| 形态 | 判定标准 | 年份例子 | 模板文件 |
|------|---------|---------|---------|
| A. 优化决策 | 目标函数+约束+最优方案 | 2021、2023 | form_A_optimization.md |
| B. 推广型 | 从特例推广到一般情形，或深入机理扩展 | 2024、2025 | form_B_generalization.md |

## 判定要点

- 优化决策：题目要求"最优""最小""最大""最佳方案"等，需要建立目标函数和约束条件
- 推广型：题目要求"一般化""推广到...情形""深入分析...机理"等，需要从特例推广到一般

形态判定与整题组合见根README。

## 通用硬约束

1. 引言段在节标题下，直接在5.3标题下
2. 先判定形态再写，不要混用
3. 引用式写法：复用前问模型时写"引用式（X），不再重复推导"
4. 优化题必须有算法选择理由和最优性/收敛性验证
5. 结果格式：按题目要求的表格格式输出，保存为resultX.xlsx
6. 反机械约束：每个公式前有文字引导、后有解释，关键推导配图，连续公式不超过3个
7. 篇幅控制：问题三约占全文25%
8. 子问结构支持：问题三含(1)(2)时，5.3.1问题(1)内嵌"模型建立→求解"，5.3.2问题(2)同理
