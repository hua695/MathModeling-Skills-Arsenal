# 论文四轮分层自审

本文件是论文 agent 与 critic 在交付前的内部自审顺序参考，不新增机器门禁。自动检查仍由 scripts 下的各 check 脚本和 delivery_gate 负责，本文件约束的是内容层人工或 agent 审查的先后次序，避免先润色后才发现论证缺口。全文完成后按需读取，按轮推进，每轮通过再进下一轮。

## 第一轮 论证逻辑

- 建立主张证据映射，方法见 `references/paper_claim_review.md`。
- 逐条判定主张类型与证据状态，先清除 unsupported，再补齐 partial。
- 检查悬空主张、证据超载、逻辑跳跃、循环论证、稻草人对比五类漏洞。
- 对核心结论做反方测试。
- 通过判据：不存在 unsupported 的核心结论，main 主张达到 supported。
- 本轮不通过不得进入后续轮次，表达层修改无法弥补论证缺口。

## 第二轮 章节结构

| 部分 | 检查要点 |
|---|---|
| 摘要 | 背景、缺口、方法、逐问数值结果、意义、边界齐备；每个数字可回溯 |
| 问题分析 | 场景与数据规模清楚，难点明确，模型选择有替代方案对比和文献依据，有整体数据流图 |
| 建模求解 | 每节有目标，模型选择说明为什么不是别的，公式从问题推导，参数有取值依据，有求解步骤，图表后有分析，子问末尾有检验 |
| 模型评价 | 创新一句话概括，局限针对本模型且具体，改进方向可操作 |

通过判据：每个子问形成题目映射、假设、符号、关系、推导、模型、算法、结果、校验的闭环，结构缺口已标注或补齐。

## 第三轮 表述质量

- 按 `references/de_ai_writing_extended.md` 逐条清洗 AI 痕迹，结果句满足数字、对比、因果三要素。
- 数字一致性：摘要、正文、图表、附录、代码中的同一数值完全相同，单位、公式编号、图表编号、参考文献编号互相吻合，同一指标精度统一。
- 美赛追加：动词强度匹配证据强度，时态一致，Related Work 按主题综合而非逐篇罗列，数值十以内用单词、以上用阿拉伯数字。
- 通过判据：无空泛结果句，无未消的硬性 AI 词命中，全文数字交叉一致。

## 第四轮 格式规范

- 纸型、页边距、字体、行距、页码符合比赛或项目 profile。
- 图题在下方、表题在上方，编号连续，三线表无竖线，图片分辨率达标，灰度打印可分辨。
- 参考文献格式统一、按出现顺序编号、正文均有对应标注、无非学术来源。
- 通过判据：格式项全部满足官方规则和 profile。

## 审查结论与分工

| 结论 | 条件 | 行动 |
|---|---|---|
| 通过 | 四轮均通过 | 进入正式交付门禁 |
| 有条件通过 | 仅第四轮非关键格式项有问题，论证完整 | 标注后由用户决定是否修改 |
| 不通过 | 第一轮有论证缺口或关键数字不一致 | 修复后回到对应轮次重审 |

自审与机器门禁互补：自审负责论证合理性、结构完整和表达质量，机器门禁负责数字一致性、证据锚点、来源存在性和格式阈值。自审通过不代表跳过 delivery_gate，机器全绿也不代表论证成立，两者都要满足。时间紧张时至少完成第一轮。
