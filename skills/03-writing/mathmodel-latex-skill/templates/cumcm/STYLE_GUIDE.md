# CUMCM 优秀论文风格规则（截图抽样版）

本文件根据 2023、2024 年多篇 C 题优秀论文页面截图归纳，用于约束 AI 生成国赛论文模板和示例稿。它只总结结构与版式，不复用优秀论文文字、图表、代码或结果。

## 1. 标准章节顺序

推荐顺序：

1. 摘要页：标题、摘要、关键词；不放目录。
2. 一、问题重述：含“问题背景”和“问题要求/问题提出”。
3. 二、问题分析：按小问分节，不单独设置“总体思路”小节。
4. 三、模型假设：编号列表，每条按“假设：解释”写。
5. 四、符号说明：三线表，列为“符号、说明、单位”。
6. 五、数据预处理：数据来源、缺失异常、参数构造；不要写成“数据读取与预处理”。
7. 六、模型建立与求解：按问题一、问题二、问题三展开。
8. 七、模型检验：误差、敏感性、鲁棒性、可行性或对比验证。
9. 八、模型评价与推广：优点、局限、推广场景。
10. 参考文献。
11. 附录：支撑材料文件列表、源程序代码说明、AI 工具使用详情说明。

## 2. 标题命名约束

- 一级标题用中文数字加顿号：`一、问题重述`、`二、问题分析`。
- 二级标题用阿拉伯编号：`1.1 问题背景`、`2.1 问题一的分析`。
- 数据章节统一叫 `数据预处理`。
- 不在正文中设置 `编译测试结果`、`LaTeX 测试说明`、`算法实现说明` 这类非论文型章节；代码运行说明应放到附录或支撑材料 README。
- 不单列空泛 `结论` 章，除非题目或论文逻辑确实需要；通常在摘要、结果分析和模型评价中收束结论。
- 不设置 `2.4 总体思路`、`总体模型思路`、`整体思路` 等教学式小节；若需要说明路线，写入各小问分析自然段或使用“模型流程图”。

## 3. 模型假设写法

推荐：

```tex
\begin{enumerate}
  \item \textbf{假设 1：} 假设内容。解释：说明该假设对应的公式、约束或数据处理理由。
  \item \textbf{假设 2：} 假设内容。解释：说明影响和后续检验方法。
\end{enumerate}
```

避免只写短句列表，也避免把题目核心难点直接假设掉。

## 4. 摘要与关键词写法

摘要按小问组织：`针对问题一...`、`针对问题二...`、`针对问题三...`。每问要有方法和结果；没有运行结果时必须使用明确占位，不能编造数值。

关键词必须优先使用数学建模教材和竞赛论文中常见的模型、方法、算法、评价或检验术语，例如 `混合整数规划`、`目标规划`、`蒙特卡洛模拟`、`风险决策`、`敏感性分析`。避免把题目对象或行业场景直接作为关键词，例如 `农作物种植策略`、`乡村农业`、`蔬菜销售`。

## 5. 图表写法

- 如需展示模型路线，推荐使用“模型流程图”，但不要因此新增“总体思路”小节；流程图必须包含数据输入、模型模块、算法求解和结果输出。
- 符号表用三线表，字段含单位。
- 数据预处理节可以放数据字典、缺失值统计、描述统计或参数估计表。
- 图表标题必须具体，正文必须引用。


## 6. 参考文献与交叉引用

- 国赛论文模板默认使用 `ref.bib` 管理参考文献，正文用 `\cite{...}` 引用。
- 图表公式引用与文献引用必须分开：`\ref` / `\eqref` 只用于图、表、公式、章节；`\cite` 只用于正文实际使用的文献、数据源或软件来源。国赛 2026 的 AI 使用通过正文声明和支撑材料详情说明，不因披露 AI 使用而添加参考文献条目。
- 不为占位文字强行添加 `表~\ref{...}`、`图~\ref{...}`。只有当图表已经存在且正文确实需要编号引用时再添加。
- 参考文献前不使用 `\nocite{placeholder-ref}`；最终参考文献列表应能追踪到正文中的引用位置。
- 交付前运行 `python scripts/check_latex_refs.py main.tex --bib ref.bib`，确保没有未定义标签、重复标签或未定义文献键。
- CUMCM 模板应保持 `hypertexnames=false`，避免附录或浮动体编号变化导致 PDF 内部链接锚点重复，从而出现跳转到错误位置的问题。


## 8. 图表题名与附录编号

- CUMCM 中文论文图表题名默认写成 `表 1 主要符号说明`、`图 1 模型流程图`，不写成 `表 1: 主要符号说明`。
- 模板使用 `caption` 宏包并设置 `labelsep=cnquad` 去掉冒号；不要在正文手工写 `表1:` 作为标题。
- 附录一级标题使用 `附录A 支撑材料文件列表`、`附录B 源程序代码说明`、`附录C AI 工具使用详情说明`，不写成单独的 `A 支撑材料文件列表`。

## 9. cumcm-extras 增强宏包快捷命令

模板默认加载 `cumcm-extras.sty`，提供以下快捷命令。不用可在 `main.tex` 中注释掉 `\usepackage{cumcm-extras}`。

### 数学符号

| 命令 | 效果 | 用途 |
|------|------|------|
| `\mat{A}` | 粗体正体 A | 矩阵 |
| `\vb{x}` | 粗体斜体 x | 向量 |
| `\trans` | T（上标用 `^{\trans}`） | 转置 |
| `\R` | 实数集 ℝ | 数域 |
| `\argmin` | arg min（下标自动） | 优化目标 |
| `\argmax` | arg max（下标自动） | 优化目标 |
| `\Var` / `\Cov` | Var / Cov | 统计量 |
| `\upcite{key}` | 上标引用 [1] | 国赛常见引用格式 |

示例：`\max_{\vb{x} \in \R^n} f(\mat{A}\vb{x})` 写为 `\max_{\vb{x} \in \R^n} f(\mat{A}\vb{x})`。

### 定理环境

```tex
\begin{definition}[矩阵可逆]
若 \(\det(\mat{A}) \neq 0\)，则矩阵 \(\mat{A}\) 可逆。
\end{definition}

\begin{theorem}[最优性条件]
...
\end{theorem}
```

支持：definition、theorem、lemma、corollary、assumption、remark、property、example、solution 等 13 种，自动按 section 编号。

### 算法伪代码

```tex
\begin{algorithm}[!htbp]
\caption{遗传算法求解流程}
\label{alg:ga}
\begin{algorithmic}[1]
\Require 种群规模 \(N\)，迭代次数 \(G\)，交叉率 \(p_c\)，变异率 \(p_m\)
\Ensure 最优解 \(\vb{x}^*\)，最优适应度 \(f^*\)
\State 初始化种群 \(P_0\)
\For{\(g = 1\) \To \(G\)}
  \State 锦标赛选择父代
  \State 交叉变异生成子代
  \State 评估适应度，保留精英
\EndFor
\State \Return \(\vb{x}^*, f^*\)
\end{algorithmic}
\end{algorithm}
```

中文关键字自动汉化：输入、输出、当、执行、如果、则、否则、遍历、返回等。

### cleveref 智能引用

```tex
如\cref{fig:framework}所示，模型流程见\cref{alg:ga}，参数见\cref{tab:symbols}。
```

自动输出："如图1所示，模型流程见算法1，参数见表1。" 支持 `\cref`（单个）、`\cref{a,b}`（多个）、`\crefrange{a}{c}`（范围）。

### 表格增强

- 三线表快捷：`\topline` / `\midline` / `\bottomline`（等价于 `\toprule` 等）
- tabularx 列类型：`Y`（居中 X 列）、`J`（左对齐 X 列）
- 跨页表格用 `longtable` 环境

### 改造版 \figplot

```tex
\figplot{模型框架图}{fig:framework}{framework.svg}{数据来源：题目附件1}
```

- 自动搜索 `./`、`./figures/`、`../02_figures/` 路径
- 文件不存在时显示占位框（不会编译失败）
- 用 `[!htbp]` 浮动（符合 figure_policy，禁止 `[H]`）
- 图宽 0.76\textwidth（figure_policy 推荐 0.6-0.85）
- 第 4 个参数为制图说明，可留空 `{}`

### 脱敏占位

```tex
\email{user@example.com}  % 编译输出 [已脱敏]
\phone{13800138000}       % 编译输出 [已脱敏]
```

防止身份信息泄露。终稿前确认所有真实身份信息已清除。

### 写作标记（终稿前必须清除）

```tex
\todo{这里需要补充敏感性分析}
\draftnote{这段是草稿，需要重写}
```

橙色 [TODO] 和红色 [草稿] 标记，终稿前必须全部清除。
