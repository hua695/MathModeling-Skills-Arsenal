# 评审校准数据采集协议

> 用途：将带证据的评审分数与官方奖项原值关联，用于后续校准分析。

## 一、目标

竞赛结束后，把每篇被评审过论文的**官方奖项结果**回流到校准库，
使 calibrated 分数 → 位次锚点从"自评样本内分布（L0/L1）"逐步逼近"真实奖项分布（L2，黄金数据）"。

## 二、采集字段（模板见 `collect_template.yaml`）

每条记录包含 9 个字段，**奖项字段只存原值，不做任何分数映射**：

| 字段 | 类型 | 说明 | 可否缺省 |
|---|---|---|---|
| paper | str | 论文标识（如 v_final / 队号） | 必填 |
| contest | str | 竞赛名（cumcm / mcm_icm / huashu / 认证杯…） | 必填 |
| year | int | 年份 | 必填 |
| problem | str | 题号（A/B/C…） | 必填 |
| final_award | str | **官方奖项原值**（如 国家一等奖 / 省二等奖 / S 奖 / 未获奖），不转换、不映射分数 | 必填 |
| raw_score | float | 我方评审 raw（0-100） | 可缺（无法评审时留空） |
| calibrated_score | float | 我方评审 calibrated（0-90，90% 封顶口径） | 可缺 |
| reviewer_evidence | str | 评审证据摘要（分数依据：门禁/WR 违规/维度分） | 建议填 |
| source | str | 数据来源（self_assessed / official_award / 众包提交） | 必填 |

**红线（不预设分数映射）**：
- `final_award` 存官方原值字符串（"省一"就存"省一"），**禁止**换算成数值（如"省一=85 分"）。
- 分数→奖项的映射关系由"锚点重建"环节事后统计拟合，采集端不做任何先验假设。
- 出现"同分不同奖"（客观存在）→ 记录为正常现象，绝不回改分数或奖项。

## 三、L1 → L2 升级规则

| 层级 | 定义 | 升级条件 | 用途 |
|---|---|---|---|
| L0 | 模拟或自评参考数据 | — | 参考分布形态，不用于位次 |
| L1 | 带证据的自评分点 | 拿到官方奖项结果 | 单调性验证，不承诺位次 |
| **L2** | 官方奖项回流（本协议产出） | 同一竞赛同年同题 ≥ 10 队，且奖项字段为官方原值 | **锚点重建的唯一依据** |

升级动作：
1. 官方结果公布后，用 `collect_template.yaml` 为每篇已评审论文填写 `final_award` + `source: official_award`。
2. 校验：`final_award` 与官方公示一致（人工核对；必要时截图存档）。
3. 达到 L2 门槛（同赛同年同题 ≥10 队）后：
   - 以 `final_award` 分组统计 calibrated 分数的分布（各奖项组的 min/P25/中位/P75/max）。
   - 用组中位构建 {score → 奖项位次} 映射 → 更新 CUMCM_ANCHORS_L0（升级为 L2 锚点），
     并清空"自评样本内分布"的 provenance，替换为 exact_contest 级别。
4. L1 数据点保留原始记录，并标注 `upgraded_to_L2: true`。

## 四、提交与合入流程

- 提交：任意 LLM/队友填写 `collect_template.yaml` 追加到 `memory/calibration_db/collected/`（每篇一个文件）。
- 合入：经人工或 `COLLAB` 审核 `final_award` 字段真实性后，写入项目指定的 L2 数据文件。
- 禁止：未经验证的自报奖项进入 L2（防刷分/误报）；模拟分进入 L2。

## 五、隐私与合规

- 论文内容不采集（红线），只采集 {paper_id, 分数, 奖项} 元数据。
- 若队伍要求匿名，`paper` 用队号或 hash，不关联身份信息。
