# 问题本质分类法

本文件在 H1 拆题和 H5 路由前（原H4已并入H5阶段一）按需读取，用于判定每个子问题的数学本质并落到能力标识。它是判定参考，不替代 `planner/problem_parser.md` 的解析，也不替代 `scripts/route_problem_profile.py` 的能力强路由；判出的本质最终要写成 problem_profile 的 capabilities，再由路由脚本映射到 profile 和附录模块。

## 第 0 步 先甄别是不是建模问题

判据：两个不同队伍解同一子问题，会不会合理地选择不同方法。会，才是建模问题；答案唯一确定的只是确定性计算。

| 分类 | 特征 | 处理 |
|---|---|---|
| 建模问题 | 要选方法、要做假设、存在方法选择空间，涉及不确定性或优化 | 进入本质判定，查选型矩阵，走证据 profile |
| 确定性计算 | 纯代数乘加、题给公式代入、min 或 max 截断、比率核算，无选择余地 | 标注为确定性计算，说明计算公式即可，不查矩阵、不套模型、不占能力位 |

题目明确要求“建立模型”时，即使表面是计算，也按建模问题处理。确定性计算仍要登记公式、输入来源和复算关系，接受数字一致性检查。

## 十二类本质与能力映射

判定后把本质转成 capabilities 中使用的能力标识，路由脚本据此选 profile。

| 本质 | 能力标识 | 信号词 | 输入 | 输出 |
|---|---|---|---|---|
| 预测回归 | prediction | 预测、估计、拟合、趋势、未来 | 历史数据与特征 | 连续值 |
| 分类判别 | classification | 分类、识别、鉴别、判断属于哪类 | 样本特征 | 离散类别 |
| 评价排序 | evaluation | 评价、排名、择优、综合评估、打分 | 多指标数据 | 得分或序 |
| 优化决策 | optimization、multiobjective | 最优、最大最小、调度、分配、路径、方案 | 决策变量与约束 | 最优解或方案 |
| 机理物理 | mechanistic、dynamics | 传热、运动、受力、场、波动、流体、光路 | 物理参数与几何 | 物理量或场 |
| 聚类分组 | clustering、grouping_threshold | 分级、聚类、划分、归类，类别数未知 | 无标签样本 | 分组标签 |
| 关联因果 | causal_correlation | 影响、关系、因素、作用、相关、贡献度 | 变量观测 | 关系强度与方向 |
| 博弈策略 | game_strategy | 博弈、策略、竞争、对抗、均衡 | 博弈规则与收益 | 均衡或策略 |
| 几何运动 | geometric_kinematic | 螺线、盘旋、碰撞、转弯半径、反射、投影、坐标、定位 | 几何参数或位置 | 轨迹、位置、角度 |
| 统计推断与实验设计 | statistics、statistical_inference | 抽样、检测、信度、拒收、收率、显著性、试验设计 | 实验或抽样数据 | 是否显著、接受域、最优条件 |
| 网络图论 | network_graph | 网络、节点、边、流、连通、路由、匹配、中心性 | 节点边数据 | 流、路径、网络指标 |
| 生态动态 | ecological_dynamics | 种群、捕食、食物链、承载力、可持续、碳、扩散 | 种群或环境参数 | 动态、指数、平衡 |

## 判定步骤

1. 提取背景、数据源、任务拆分、硬软约束、优化目标。
2. 对每个子问题按信号词和输入输出判一个主本质，必要时加次本质。
3. 写清输入变量、输出目标、约束和难点，不用本质标签替代具体描述。
4. 把本质转成能力标识，供 problem_profile 和路由使用。
5. 标注子问题之间传递的具体数据，形成数据流。

## 混合类型与数据流

一个子问题可含多种本质，按“前置类型先做、结果作为后置类型输入”排序。

| 混合模式 | 数据流 |
|---|---|
| 评价加优化 | 先评价各方案，再以评价结果为目标做优选 |
| 预测加优化 | 先预测未知量，再把预测值代入优化模型 |
| 机理加优化 | 先建机理关系，再在机理约束下优化控制量 |
| 机理加几何 | 先立物理方程，再叠加几何约束求解 |
| 聚类加评价 | 先无监督分组，再对各组评价排序 |
| 分类加关联 | 先分类，再分析各因素对类别的贡献 |
| 生态加优化 | 先建种群或碳流动态，再优化捕捞或配置策略 |

主本质决定主 profile，次本质作为附加能力参与证据要求；混合问题在 model_contract 中分别列出各能力，证据要求按能力合并去重。
