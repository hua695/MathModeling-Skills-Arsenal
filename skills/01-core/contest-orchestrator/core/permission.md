# 权限模式

## 模式

| 模式 | 适用条件 | 权限 |
|---|---|---|
| `AUTO` | 已授权范围内的常规推进 | 自主完成低风险计算、实验、排版和检查；触发止损时自动收敛 |
| `COLLAB` | 需要用户确认的关键节点 | 自动完成可逆计算；模型族、核心假设、架构、定稿和正式交付须暂停确认 |
| `LOCK` | 冻结与提交阶段 | 模型、数据、参数、结果和提交版本不可变；只允许排版、可验证修复、图表美化和门禁检查 |

## Emergency Stop

满足任一条件时停止探索并进入收敛：剩余时间低于 15%、论文完成度超过 80%、新路线预期收益不足或风险超过项目阈值。收敛优先保障论文完整性、摘要、主问结果、证据和交付门禁。

## 权限边界

`AUTO` 可执行参数微调、baseline 验证、补充实验、时间重排、格式修复、数据清洗、出图和复现检查。以下动作在 `COLLAB` 下必须确认：更换模型族、改变实验设计、增加核心假设、切换架构、修改核心参数和论文定稿。`LOCK` 阶段禁止改变题意、核心假设、模型结构、数据来源、结果和提交版本。

## 任务复杂度

| 复杂度 | 默认流程 |
|---|---|
| `simple` | problem parser → baseline → solve → paper；按需关闭文献和实验扩展 |
| `medium` | 标准 A–G 流程 |
| `hard` | 全模块、候选路线并行、完整证据和可靠性检查 |
