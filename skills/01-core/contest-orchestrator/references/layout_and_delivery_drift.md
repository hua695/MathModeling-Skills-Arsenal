# 版面反模式与正式交付防漂移

详细的图表路由、尺寸边界和布局模式以 `references/figure_policy.md` 为唯一权威。本文件只列出版面反模式和交付防漂移检查，避免重复维护同一套字段。

## 源文件层版面规则

- 正文图表默认使用 `[!htbp]`；`figure/table[H]` 会锁死浮动体，容易把正文推到下一页，严格交付直接阻断。
- 导言区必须加载 `placeins` 并使用统一浮动参数；具体数值只维护在 `figure_policy.md`。
- 图文穿插：两张独立浮动体之间必须有正文段落；并排块内部的左右面板不视为两张连续浮动体。
- 图随文走：图片必须放在首次 `\ref` 引用的文字之后 1 到 2 段内，不得跨章浮动；每章末尾加 `\FloatBarrier`。
- 版面入口必须与登记的 `layout_mode` 一致；不得用裸 `\includegraphics`、未约束的 `\includesvg`、手工负间距或强制 `[H]` 绕过布局契约。
- 不得连续使用 `\clearpage`、`\newpage` 或 `\pagebreak` 凑页数；文献、附录分隔只保留必要的一次分页。
- 大段 `\vspace` 只能有明确的版式理由。检查器会记录超过 24pt 的手工留白，严格模式下仍允许通过，但必须人工确认不是凑页数。
- 正文页数低于竞赛下限时，应补充真实的建模思路、推导、算法边界或结果解释；禁止增大字号、插入空白页或堆叠分页。

## 公式、表格和图引用

- 每个 `\ref`、`\eqref`、`\pageref`、`\autoref`、`\cref` 必须对应唯一 `\label`。
- 未定义引用和重复标签在编译前阻断；不要把“编译器会提示”当作审计流程。
- `check_tex_references.py` 会展开 `\input`/`\include` 后检查全部章节文件。

## 正式交付防漂移

当项目存在 `05_输出与交付/正式交付` 时，正式版 PDF 必须与当前编译 PDF 内容相同，`FINAL_INDEX.md` 必须登记当前 PDF 的 SHA-256。源文件修改后重新编译，不能继续沿用旧正式版或旧索引。

检查器只把名称包含“正式版”“final”或“submission”的 PDF 视为正式交付件；其他历史资料不会被静默当成当前提交件。
