# 方法选择核心原则与防炫技机制

> **适用范围**：全国大学生数学建模竞赛所有题型，B 题（优化决策类）优先适用。
>
> **核心原则**：方法适配问题，而不是越复杂越好。复杂方法不是默认候选，而是"经论证后获得准入资格"的候选。

---

## 一、6 条防炫技核心原则

### 原则 1：模型复杂度必须由问题复杂度驱动，而不是由算法能力驱动

> 看到问题 → 理解问题结构 → 选择匹配的方法
>
> 而不是：看到问题 → 搜索高级算法 → 套模型

### 原则 2：没有 baseline，不允许直接使用复杂模型

每个小问必须先交付一个简单基线模型。baseline 不一定最终写进论文，但必须存在。

### 原则 3：没有证明简单模型失败，不允许升级

复杂方法只有在简单模型存在明确失败点时，才能作为候选。失败点必须具体，不能说"简单方法不够好"。

### 原则 4：没有显著增量价值，不允许保留复杂模型

复杂模型必须用消融、对比、敏感性或稳健性实验证明其增量价值。如果只是精度微升但解释性大幅下降，通常不值得。

### 原则 5：无法解释现实意义的模型，不应作为论文主模型

复杂模型不能只输出"模型效果更好"，必须能回答：哪些变量最重要、为什么影响方向是这样、参数变化对结果有什么影响、结论与现实机制是否一致。

### 原则 6：如果两个模型效果接近，优先选择更简单、更稳定、更可解释的模型

竞赛不是算法大赛，评委更看重问题理解和建模扎实程度，而不是算法名字的高级程度。

## 二、Baseline-first 强制流程

### 2.1 各题型 baseline 推荐

| 题型 | 推荐 baseline |
|------|--------------|
| 优化题 | 贪心算法、规则法、线性规划（小规模） |
| 预测题 | 均值法、线性回归、移动平均、ARIMA（基础版） |
| 评价题 | 简单加权、熵权法、TOPSIS（基础版） |
| 分类题 | 逻辑回归、决策树（深度≤3） |
| 机理题 | 最基本的守恒关系、几何关系、微分方程（线性化） |

### 2.2 强制比较指标

复杂模型与 baseline 对比时，至少包括：

1. **精度提升**：误差下降了多少？是否显著？
2. **稳定性**：参数扰动下结果波动如何？
3. **解释性**：能否说清楚每个变量的作用？
4. **计算成本**：运行时间增加了多少？
5. **对参数变化敏感度**：参数微调是否导致结果剧变？
6. **是否改变最终决策**：换成 baseline，最终结论/排序/策略是否改变？

### 2.3 典型"不值得升级"的信号

如果复杂模型只是：
- RMSE 从 0.213 降到 0.207（提升 <3%）
- 计算时间从 2 秒变成 5 分钟（成本增加 150 倍）
- 解释性大幅下降（从"每个系数有意义"变成"黑箱"）
- 最终排序/决策没有改变

那么通常没有必要使用复杂模型。

## 三、决策影响测试

### 3.1 核心问题

> 如果换成更简单的方法，最终结论、排序、策略、决策是否改变？

### 3.2 决策影响等级

| 等级 | 定义 | 复杂模型必要性 |
|------|------|---------------|
| 0 | 最终结论完全不变 | 很低，建议用简单方法 |
| 1 | 局部数值变化但结论不变 | 低，建议用简单方法 |
| 2 | 部分排序或策略变化 | 中等，需要论证 |
| 3 | 核心结论发生变化 | 高，复杂模型有价值 |

### 3.3 使用规则

- 复杂模型最好至少达到等级 2，否则应谨慎采用
- 等级 0 或 1 的复杂模型，除非有其他明确价值（如解释性更强），否则建议降级

## 四、方法适配性检查（7 问）

在选择方法前，必须回答以下 7 个问题：

### A. 问题结构（3 问）

1. **核心矛盾是什么？**（用一句话说清楚）
2. **题目真正要求的是预测、解释、优化、评价还是决策？**
3. **数据规模、维度和噪声水平是否支持该方法？**（样本量够不够？有没有标签？量纲是否齐？）

### B. 方法匹配（2 问）

4. **该方法具体解决核心矛盾的哪一部分？**
5. **该方法要求的前提假设是否满足？**（正向：题目→假设；反向：假设→题目）

### C. 升级合理性（2 问）

6. **简单方法具体失败在哪里？**（必须具体，不能说"不够好"）
7. **复杂方法是否直接针对这些失败点？性能提升是否足以抵消复杂度、解释性和计算成本？**

## 五、方法选择质量评分表（100 分制）

| 维度 | 权重 | 打分锚点 |
|------|------|----------|
| 核心矛盾识别 | 15 | 能用一句话指出题目核心矛盾并贯穿全文=13-15；识别了但不聚焦=8-12；没有=0-7 |
| 方法必要性（vs 简单基线） | 25 | 有明确基线对比且量化证明复杂方法更优=22-25；有理由但无对比=13-21；无理由=0-12 |
| 假设合理性 | 15 | 每条假设有"简化什么+代价是什么"双要素=13-15；只有简化没有代价=8-12；凑数假设>3条=0-7 |
| 数据/信息适配度 | 15 | 显式论证样本量/维度/分布支撑该方法=13-15；默认成立=0-8 |
| 可验证性 | 15 | 有退化验证+交叉验证/灵敏度分析+结果与常识对拍=13-15；只有一项=7-12；无=0-6 |
| 可解释性 | 10 | 核心结论能用非技术语言解释=9-10；部分可解释=5-8；只能说"收敛了"=0-4 |
| 复杂度预算 | 5 | 方法数≤题目小问数+1且无跳跃升级=5；否则=0-3 |

### 使用规则

- **≥90 分**：非常扎实，可作为主模型
- **80-89 分**：较好，可以使用
- **70-79 分**：基本可用，但需要优化
- **60-69 分**：存在明显方法选择问题
- **<60 分**：建议重新选模型

### 硬门禁

如果以下任一维度低于阈值，不允许进入最终论文：
- 核心矛盾识别 < 12
- 方法必要性 < 13
- 假设合理性 < 8

## 六、模型-假设一致性检查

### 正向检查：题目条件 → 是否支持模型假设

逐条检查模型的每个假设是否能从题目条件或常识中推导出来。

### 反向检查：模型需要的假设 → 题目是否真的允许

逐条检查模型运行所需的前提条件，题目是否真的提供或允许。

### 常见"为算法造假设"的信号

| 算法 | 常见强行假设 |
|------|-------------|
| 强化学习 | 强行构造奖励函数、假设环境可交互 |
| 马尔可夫链 | 强行假设无后效性 |
| 线性规划 | 直接假设所有关系线性 |
| 神经网络 | 假设样本量足够、假设数据有非线性结构 |
| 时间序列模型 | 假设有时间依赖结构（实际只是普通表格数据） |

如果模型需要的条件无法由题目或数据支持，应降低优先级或更换方法。

## 七、复杂度升级树（B 题优化类）

```text
解析解
  ↓（解析解不存在或太复杂）
线性规划（LP）
  ↓（有整数决策变量）
整数规划（MILP）
  ↓（有非线性目标或约束）
非线性规划（NLP）
  ↓（多目标冲突）
多目标规划（MOO）
  ↓（规模大、NP-hard、精确求解不可行）
启发式算法（GA/SA/PSO）
  ↓（动态决策、序列决策、环境可交互）
强化学习（RL）
```

### 使用规则

1. 模型只能在前一级明显不足时继续升级
2. 禁止跳跃式升级（如从线性规划直接跳到强化学习）
3. 每次升级需要在任务卡中留一条"升级记录"：上一层的哪个缺陷促使升级

## 八、方法名剥离审查（写作完成后自检）

### 操作方法

把摘要和正文中所有方法名（"LSTM""NSGA-II""熵权法"等）遮掉，只看逻辑链：

```
问题是什么 → 建立了什么关系 → 怎么求解 → 结果如何
```

### 判断标准

- **逻辑链在遮住术语后仍成立** = 方法为问题服务，扎实
- **一遮术语就散架** = 术语堆砌，炫技

### 典型"一遮就散"的信号

- 遮住方法名后，不知道模型在做什么
- 整篇论文的核心价值就是"用了 XX 高级方法"
- 没有方法名就说不清楚结果是怎么来的

## 九、B 题（优化决策类）特别提醒

### 9.1 优化题的扎实方法优先级

| 优先级 | 方法 | 适用场景 |
|--------|------|----------|
| P0 | 贪心算法、规则法 | 有明显贪心结构、小规模、快速 baseline |
| P0 | 线性规划（LP） | 目标和约束都是线性的 |
| P1 | 整数规划（MILP） | 有整数决策变量、规模适中 |
| P1 | 非线性规划（NLP） | 有非线性目标或约束、可求导 |
| P2 | 动态规划 | 有最优子结构、无后效性 |
| P2 | 多目标规划 | 有多个冲突目标 |
| P3 | 启发式算法（GA/SA/PSO） | 仅当精确求解不可行、规模大、NP-hard |
| P3 | 强化学习 | 仅当动态决策、环境可交互、状态转移未知 |

### 9.2 B 题炫技高风险信号

1. **小规模优化用启发式算法**：几十个变量本来可以精确求解，却用 GA/PSO"近似"
2. **静态优化用强化学习**：一次性优化问题直接上 PPO/DQN
3. **存在解析解却用数值优化**：公式可以直接推导，却用黑箱优化器搜索
4. **每小问都换一个全新方法体系**：三个问题三个领域，没有统一建模视角
5. **启发式算法不给数学规划模型**：只说"用了遗传算法"，不说优化目标和约束是什么

### 9.3 B 题 baseline 推荐

- **问题一**：通常是基础建模，优先用解析方法或简单 LP
- **问题二**：在问题一基础上扩展，优先用 MILP 或 NLP
- **问题三**：如果是复杂优化，先做贪心 baseline，再考虑启发式
- **问题四**：如果是综合应用，优先用前面建立的模型扩展，不要另起炉灶

---

## 十、最重要的三句话

1. **复杂方法不是默认候选，而是"经论证后获得准入资格"的候选。**
2. **没有 baseline，不允许直接使用复杂模型；没有证明简单模型失败，不允许升级。**
3. **如果两个模型效果接近，优先选择更简单、更稳定、更可解释的模型。**
