# 外部提示词吸收规则

本文件记录从外部“万能建模提示词”和“自动自查表”中吸收的可执行部分。它不是新的全局竞赛规范。

## 进入现有流程的内容

- A 阶段：逐小问登记目标、已知条件、约束、输出和题型；有附件时建立字段、单位、缺失值和异常值审计。
- B 阶段：模型方案登记核心原理、场景适配性、备选方案、局限和创新机会；不得为了“冲奖”强行增加复杂模型。
- C 阶段：记录算法选择理由、参数来源、终止条件、约束处理和结果来源；图表只按论证需要生成。
- D/E 阶段：每个子问题形成“思路—推导—求解—结果—检验”闭环；自查报告定位到页码、段落或文件，不用关键词存在代替内容证据。
- F 阶段：检查题面覆盖、模型—代码—数据—图表一致性、匿名信息、附录顺序、支撑材料和正文引用。

## 明确不进入全局硬门禁的内容

固定公式数量、固定假设数量、固定图表数量、统一扰动比例、固定摘要字数、固定正文最低页数、强制使用 Python/Matlab，以及“自动识别 AI 痕迹并直接判违规”均不得写成全局规则。

这些要求只能在题型或竞赛 profile 明确提供官方依据时启用；否则作为建议或人工复核项。

## 国赛 2026 AI 合规 profile

`planner/competition_profiles/guosai_2026_ai.json` 对应官方规定。正式交付时由 `check_ai_compliance.py` 检查：

1. 参考文献前存在 AI 工具使用声明；
2. 使用 AI 时，支撑材料中存在 `AI工具使用详情.pdf`；
3. 详情文件能够说明工具版本、用途环节、关键提示/交互摘要和人工核验；
4. AI 工具不因本项说明而自动加入参考文献表；只有独立的软件、数据或研究来源被正文引用时，才按引用规则登记；
5. 声明只写实际使用范围的必要信息，但必须真实完整，不得通过省略已使用工具或虚构“未使用”规避规定。

官方规定生效日前只登记为 INFO，不阻断其他竞赛或当前测试；生效后缺少声明或详情文件才 BLOCK。
